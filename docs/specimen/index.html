Every element a piece of writing can use

A reference for whoever lays out the next post. The rules are in STYLE.md. This page shows them at work.

Prose is set in IBM Plex Serif, about seventy characters to the line. Emphasis is italic, strong emphasis is semibold, and a link is underlined in grey until it is pointed at. The names of things in code, such as lightcone.js, are set in the mono face. A note is marked like this.1

Side heads

A second-level heading sits in the margin, beside the paragraph it introduces, in the same face and size as every other label on the site. On a narrow screen it moves above the paragraph. Keep side heads to a few words.

A third level, used sparingly

It stays in the text column. A piece that seems to need a fourth level needs restructuring instead.

Lists

  • Unordered items are marked with a dash.
  • They keep the measure of the text around them.
  1. Ordered items are numbered in the mono face.
  2. Use them only when the order means something.

Mathematics

Mathematics is written as TeX and set by KaTeX. Inline, neutral hydrogen radiates at \(\nu \approx 1420.4\ \mathrm{MHz}\), a wavelength of \(\lambda = c / \nu \approx 21.1\ \mathrm{cm}\). On a line of its own, an equation is set flush left:

\[ N = R_{*} \, f_p \, n_e \, f_l \, f_i \, f_c \, L \]

Code

def fold(signal, width):
    """Cut a line of bits into rows of the same length."""
    return [signal[i : i + width] for i in range(0, len(signal), width)]

Figures

A figure is as wide as the text column unless it is marked wide, in which case it spans the margin too. Its caption starts with its number and is a full sentence.

Figures that respond

A figure may respond to the pointer. It has to make sense before anyone touches it and with scripts turned off, and the orange is spent only while it is being handled.
